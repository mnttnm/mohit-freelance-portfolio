# mohittater.in

Personal portfolio and freelance services site for Mohit Tater — Product Engineer & Consultant.

## Stack

- [Astro](https://astro.build) (static output)
- Deployed on [Vercel](https://vercel.com)
- Google Fonts (DM Serif Display, Instrument Sans)

## Development

```bash
npm install
npm run dev
```

## Build & Preview

```bash
npm run build
npm run preview
```

## Deploy

Connected to Vercel — pushes to `main` trigger automatic deploys.

Framework preset: **Astro**. No additional configuration needed.
